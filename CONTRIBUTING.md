# Contributing to the Pactora site

Thanks for helping.

## Run it

```sh
npm run serve
```

Open `http://127.0.0.1:8765`. Nothing needs installing.

## Before you open a pull request

- Run `npm run check`. It parses every module and checks that every image and link target exists.
- Look at your change at phone width (390 px) and desktop width, and with reduced motion turned on.
- Add screenshots to the pull request.

## Copy rules

The page talks about a token, so the wording matters:

- No promises of profit, price, returns or ownership.
- Holder benefits are "planned" or "announced once live" until they actually exist.
- Paid KOL promotion is always called out as paid.
- Token numbers live only in `site/config.js` and the facts in `index.html`. Change both together.

## Art

Only add images you made or have the right to publish under this repository's MIT license. Say where each new image came from in your pull request.

By contributing, you agree that your work is released under the MIT License.
